# DAF Worksheet — every entry is a future question

The Detailed Application Form is the panel's question bank. Rule: **for every line
you write, pre-answer the 3 questions it can generate.** Fill this during the Jan
ramp (post-Phase-1); draft columns now so the DAF writes itself later.

## The 3-question rule

| DAF entry | Likely questions | My pre-answers |
|---|---|---|
| _(each degree)_ | Why this branch? Favourite subject? One concept explain simply? | |
| _(each job)_ | What did you build? Why leave? Conflict with a manager? | |
| _(each project)_ | Explain it in 60s. Your specific contribution? What broke? | |
| _(each hobby)_ | Latest thing in it? What does it say about you? | |
| _(achievements)_ | What did it take? Who else was involved? | |
| _(gap periods)_ | What were you doing? Proof you're not rusty? | |

## Fill-in skeleton

- Name/education/city — nothing to prep, but expect "tell us about your hometown."
- **Hobbies: list only 2–3 you can defend for 5 minutes.** "Reading" invites
  "last book?"; "trading" invites hard follow-ups (good — you know this stuff).
- Family background — short factual answer, no oversharing.
- Anything unusual (name spellings, career pivots, gap years) — they WILL ask;
  have a calm 30-second true answer.
